Core beliefs

Eight ideas everything else is built on.

01

Why before how

Never start with the formula. Start with the problem it was invented to solve.

02

Logic over memorization

Understand the logic and you don't need to memorize — you can rebuild it.

03

Story first, symbols second

Coordinates become map addresses. Ratios become sharing pizza.

04

See it, then solve it

If you can see the idea moving, you can understand it.

05

No jargon, no shame, no rush

06

Start from zero

Never assume you remember the last chapter. Rebuild the foundation every time.

07

Every mistake is a clue

08

The Numeris loop

The same five steps, every problem.

1

Ask the question

Bring the problem exactly as it is — no need to simplify it first.

2

Understand the why

See what the problem is actually asking, before any method gets named.

3

See it visually

Watch the idea move, not just sit on the page as symbols.

4

Try it yourself

Take the next step. Numeris catches it if it goes sideways.

5

Explain it back

Put it in your own words. That's how you know it stuck.
